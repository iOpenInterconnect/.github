## Welcome to iHub

Lightweight, easy and beautiful way to automatically install, manage and display your Open Source iOS implementations
Attempting to make projects more accessible and easier to use for everyone

```
> UxPlay
> libimobiledevice
> OpenDrop
> ...more to come!
```

Root of this project is https://github.com/iOpenInterconnect/ihub-cli
```
> A library of handpicked Open Source iOS implementations
> Install, uninstall and view each project
```

Main repo of this project is https://github.com/iOpenInterconnect/tui
```
> A TUI specifically designed to work in termina*
> Easy, lightweight, yet beautiful
> Build your own Hub with customizable windows and startup applications
```

Check every project available in https://github.com/iOpenInterconnect/ihub-cli
